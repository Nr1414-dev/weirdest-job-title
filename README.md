Entry for the [make.fun bounty "Weirdest Job Title: Blind Judge Showdown"](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922).

The program writes exactly one job title to `/output/entry.txt`:

> Thermostat War Mediator

Office thermostat wars are a universal shared experience, and a mediator
for them is a real-sounding job with one gloriously specific twist — two
coworkers glaring at one thermostat, a mediator between them. It is 23
characters, reads instantly, and dodges every crowded cluster in the
field (no apologizer, mourner, goldfish, geese, penguin, billionaire,
sock, printer, elevator, microwave or pigeon).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is exactly one job title, 23 characters, no trailing newline.
The file is written directly and given mode 0644.
